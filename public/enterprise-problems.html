엑셀로 관리하던 업무를 시스템으로 옮기거나, 기존 시스템에서 이어지지 않는 업무를 연결합니다.

승인과 처리 현황을 따로 확인한다면

누가 요청하고, 승인하고, 처리하는지 업무 순서와 권한을 정합니다. 담당자가 바뀌어도 진행 상황을 확인할 수 있게 만듭니다.

같은 정보를 여러 번 입력하고 있다면

부서별 입력 항목과 데이터 흐름을 정리합니다. 한 번 입력한 정보를 필요한 업무에서 이어 쓸 수 있도록 시스템 간 연결을 설계합니다.

현업이 필요한 기능을 따로 관리한다면

엑셀이나 별도 문서로 관리하는 업무를 확인합니다. 새로 필요한 기능과 기존에 유지할 기능을 나눠 필요한 범위부터 개발합니다.
