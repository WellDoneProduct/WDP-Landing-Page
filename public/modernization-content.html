AI 분석에 사용할 소스코드와 자료는 어떻게 공유하나요?

보안 협약(NDA)을 맺은 뒤, 고객사가 정한 방식(사내 저장소 접근, 폐쇄망 반입 등)으로 공유받습니다. 분석 환경과 접근 권한은 사전에 함께 정합니다.

기존 기능과 업무 정책은 어떻게 보존하나요?

코드에 담긴 계산식·예외 처리를 업무 규칙으로 정리하고, 전환 후 원본과 처리 결과를 대조해 누락과 차이를 보완합니다.

내부 IT팀은 얼마나 참여해야 하나요?

분석과 변환·보완은 웰던프로덕트가 수행합니다. 내부 IT팀과 현업은 중요한 업무 기준 확인과 검수 시나리오 합의에 참여합니다.

무료 미팅 전에 무엇을 준비하면 되나요?

현재 사용 중인 기술과 시스템 규모, 전환하려는 이유 정도면 충분합니다. 소스코드는 상담 이후 필요할 때 공유받습니다.

기능 명세서가 없어도 가능한가요?

가능합니다. 문서 대신 기존 소스코드와 실제 화면·데이터를 기준으로 업무 규칙을 분석합니다.

데이터베이스도 반드시 바꿔야 하나요?

아닙니다. MS SQL Server와 기존 프로시저는 유지할 수 있으며, DB 교체 여부는 비용과 운영 조건을 보고 별도로 결정합니다.

화면과 업무 방식도 모두 달라지나요?

업무 흐름은 그대로 유지하는 것이 기준입니다. 익숙한 입력 방식은 살리고, 불편한 화면과 반복 조작만 개선합니다.

운영 중인 시스템도 전환할 수 있나요?

가능합니다. 운영을 멈추지 않도록 전환 범위를 나누고, 병행 검증 후 단계적으로 전환합니다.

기간과 비용은 어떻게 정하나요?

코드 규모와 상태, 전환 범위, 외부 연계와 검증 요건을 확인해 산정합니다. 30분 무료 상담 후 범위별로 안내드립니다.
